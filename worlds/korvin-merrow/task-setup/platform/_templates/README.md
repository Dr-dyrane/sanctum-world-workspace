# Golden template (world house style)

`golden-template-worldstyle.docx` is the reusable golden shell, Mode-A-derived from the live world pharmacy note so it carries the exact world chrome (Mercy Vale letterhead band, identity table, Arial, the EEF1F4 band, house-style electronic signature).

USE: copy it per task, fill the per-task fields ([DATE], [Document type], [DELIVERABLE TITLE], the author block) and the body, render + integrity-gate, physician sign-off.

Korvin's identity bands (name/DOB/MRN/FIN/allergies/unit/attending/code) are the SAME for all six goldens, so they stay; only DATE, DOCUMENT, TITLE, author, body, and signature change per task.

Two bars, both required: (1) DESIGN from this template (cheap, holds the standard); (2) REGISTER from the GR examples in the instruction doc - terse attending shorthand, not full prose. Date field is plain 'DATE', never 'DATE / ANCHOR' (Abi). No fabrication; placeholders for gaps; must score full under its own grader.
