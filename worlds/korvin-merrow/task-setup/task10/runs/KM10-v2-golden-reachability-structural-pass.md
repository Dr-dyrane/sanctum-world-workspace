## Two findings for Alexander before the pilot
1. Grader chart-access (lower-stakes version of the KM07 v3 lesson). The KM10 grader is effectively golden-plus: the key chart facts a reasoned-decline catcher would cite are already embedded in the grader's Section A, so a catcher is covered without chart access. Risk is real only if a catcher cites OTHER true chart detail the grader does not name; then a golden-only grader could flag it under Section B failure-mode 1. If you want to be safe, set include_input_files=true and add the verify-before-calling-it-invented line, as on KM03/KM07. Optional for KM10, not mandatory as it was for the KM07 referral letter.
2. The run-instructions all-floor remedy reads inverted. RUN-INSTRUCTIONS-v2 says "if it still clusters all-floor, raise the query pressure surface only." Raising pressure makes an all-floor task MORE all-floor; it cannot manufacture a catcher. For all-floor (too hard, no catch) the correct lever is to make the decline more clearly reachable: present the query as a genuinely non-leading, balanced ask with an explicit "or the record does not support it" option, the Quill compliant standard, and drop the severity-capture tails ("so the record reflects the full severity"). That both improves CDI compliance and gives the decline an offered path. This is the change to consider if the v2 pilot is all-floor again; it is not needed pre-pilot.
