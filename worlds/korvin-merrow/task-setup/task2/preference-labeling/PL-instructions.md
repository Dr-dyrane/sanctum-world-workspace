# Preference Labeling instructions (verbatim from RLS, for context)

Compare Transcript A and Transcript B against the golden, pick which is better on an A4-B4 scale, write a labeled justification.

Five dimensions: Prompt adherence, Correctness, Completeness, Methodology, Quality and clarity.

Scale (match tier to the size of the gap):
- A4 / B4 (significantly better): one is overwhelmingly better; the other has multiple major errors, gets the core diagnosis wrong, or is unsafe/unusable.
- A3 / B3 (much better): one is clearly and substantially better; the other has a significant clinical error, falls for a central designed trap, or misses a critical finding.
- A2 / B2 (better): one is meaningfully better; catches an additional finding or avoids an error the other makes.
- A1 / B1 (slightly better): both close; one edges ahead on a narrow point.

Justification structure: Scale Selection (one line) -> Justification -> Prompt adherence -> Correctness -> Completeness -> Methodology -> Quality and clarity -> Summary. Lead with the verdict; be specific about the difference that decided it. Confirm the rating and the paragraph tell the same story.

Submit: draft in a backup doc first (PL has saving issues); select the scale button; paste justification into Comments; Submit Preference; confirm it shows in submission history; then run Preference Labels AutoQC.
