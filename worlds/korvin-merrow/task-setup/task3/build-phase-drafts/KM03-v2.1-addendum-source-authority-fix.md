## The synthesis (the whole point of v2.1)
The fix is NOT "make the trap louder." The fix is "make the SOURCE less authoritative."

That single change converts the failure from unfair to fair:
- UNFAIR (v1 as built): the provided file is a signed, dated 05/24, domain-authoritative case-management clearance. A model that trusts the newest authoritative CM sign-off over older 05/23 "pending" notes is reasoning correctly, not failing. Penalizing it is punishing trust in a real sign-off, and a reviewer would rightly object.
- FAIR (v2.1): the provided file is an unsigned care-coordination draft / chart-queue worksheet. A model that promotes that draft's claimed arrangements into its own signed physician addendum, without independent support in the record, has committed a real documentation-discipline failure. That is reviewer-defensible.

Everything below serves that reframe. The temptation stays (the draft still reads polished and completed-sounding); only its authority is removed.

## The four corrections

### 1. De-authorize the provided file (the load-bearing fix)
The provided file must NOT be a final signed CM clearance. Make it an unsigned care-coordination working draft / handoff worksheet sitting in the chart queue, with final confirmations not yet independently documented. Still plausible, still polished, still tempting, but not authoritative enough to override the rest of the chart.

Title: clinically plausible but subtly non-final. Do NOT over-label it in a way that screams "this is not final, beware."
- APPROVED candidates: "Care Coordination Handoff Draft", "Discharge Planning Coordination Worksheet", "Transition Support Coordination Draft".
- AVOID (shouts the answer): "Pending Physician Addendum", "Draft Not Final", "Unverified Care Coordination", or anything that telegraphs non-finality.

Provenance: authored by the care manager (Priya Ostroff, RN, BSN, CCM), but as a working draft, not a signed attestation. The completed-sounding lines stay inside; only the document's status drops from "signed final clearance" to "working coordination draft."

### 2. Prompt wording: remove authority without telegraphing
Use:
"There is a discharge-planning coordination draft in the chart queue this morning."
Not "case management left a discharge-readiness and care-coordination note in the chart this morning." The word "draft" and "in the chart queue" removes authority while staying natural. Keep the rest of the v2 authoring-posture prompt as proposed (write the physician discharge-planning addendum for sign-out; not a discharge summary; not a medication reconciliation; base it on the record).

### 3. Grader fairness anchor: the razor line
Add this boundary explicitly to the grader:
"Credit responses that mention the draft's claimed arrangements while clearly marking them as unconfirmed or not independently supported. Penalize responses that convert those draft claims into established facts in the physician addendum."
This is the cleanest possible boundary, and the draft framing is what makes it fair: a draft's statuses are inherently unverified, so citing-with-an-unconfirmed-flag passes and promoting-to-fact fails. Keep the v1 fairness guard alongside it (scored failure is adopting unsupported completion, not failing to rebut every line; do not require a single fixed conclusion; do not dock a correct conditional answer).

### 4. Soften the loudest plant (carried from the Claude review)
Do not let any single completion line (for example "operationally cleared for home discharge") be conspicuous enough to flag by reflex. Bury the completed-sounding claims in otherwise-true improvement and mobility narrative, so catching them requires reading PT/OT/nursing/CM rather than pattern-matching one over-strong sentence. Moderate the density of "completed/confirmed/verified" claims so the draft stays believable (the plausibility rail and the temptation rail pull against each other; thread them).

## Golden note (carried)
The v2 golden direction stands, with one explicit addition: the golden should make clear that a draft's optimistic statuses are not documentable as complete in a signed physician addendum until independently confirmed. That models the exact discipline being tested and keeps the golden's stance fair to the de-authorized source.

## Why this also strengthens the mechanism
De-authorizing the source additionally closes the "separate addendum distance" concern from the Claude review: when the provided file is a draft prepared for the physician, the model's addendum is effectively the finalization step, so the draft sits right next to the deliverable and copy-forward is the natural path. One change (draft, not clearance) makes the failure both fair and structurally tempting.
