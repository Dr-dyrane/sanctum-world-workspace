## Source-Of-Truth Rule

- Design tasks before files.
- Every essential file exists because a task needs it for the correct answer.
- Supplementary files should not change any correct answer if removed.
- World-level file IDs use D#.
- Task-level essential file IDs use E#-T#.
- Supplementary files use D# or S# / S#-T# as appropriate.

## Reviewer / AutoQC Risk

- Starting Section 3 file inventory before task specs are decided risks backwards design.
- File plan must have complete columns in final spec.
- Supplementary files must not carry hidden trap content.
- No single file should resolve a task alone.
