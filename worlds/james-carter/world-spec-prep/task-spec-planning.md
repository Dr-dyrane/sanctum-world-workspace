# Task Specification Planning

## Already Locked From Brainstorm

Six primary rough tasks:

1. Discharge medication reconciliation / medication safety review
2. Hospital discharge summary generation
3. Transition-of-care / discharge readiness plan
4. Post-hospital follow-up assessment note
5. Consultant recommendation synthesis / care coordination note
6. Readmission risk / patient safety review

Workflow mappings:

- P0: Discharge Medication Reconciliation
- P0: Hospital Discharge Summary Generation
- P0: Discharge Planning Documentation
- P0: Transitional Care Management Documentation (TCM)
- P1: Interdisciplinary Care Plan Development and Documentation
- P0: Patient Risk Stratification Assessment

## Needs Physician Decision

- Final task titles.
- Naturalistic draft task prompts in Alexander's voice as physician writer.
- Who is doing the work, training level, setting, and clinical moment for each task.
- Expected output format, length band, voice, and specific grading anchors.
- 5-6 highest-yield failure-design items per task, with remediation paths.
- Whether any task-level files are truly necessary or whether world-level files are enough.

## Source-Of-Truth Rule

- Task prompts must be human-created by Alexander.
- Each task must be independent.
- Each task must have an explicit anchor after the world close.
- Each task should produce one concrete, evaluable deliverable.
- Prompt should not hint that a trap exists.

## Reviewer / AutoQC Risk

- Brainstorm task descriptions are not final task prompts.
- Too much overlap between discharge-related tasks may look duplicative unless distinct competencies remain explicit.
- Expected outputs must be precise enough for grading without becoming golden responses.
- Task-level traps must remain distinct from shared world-level traps.
