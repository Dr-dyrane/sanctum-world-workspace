# Fresh-eyes reset: frozen world is a constraint, not a verdict

Date: 2026-06-14

This report supersedes the mood, not the facts, of the cold-vs-warm escalation notes. The recent pilots proved several surfaces weak. They did not prove the Ondina world is unusable.

## Headline

The world has enough clinical complexity. It has 34 finalized world files, a limb-threat diabetic foot infection, real payer pressure, functional unsafety, perfusion uncertainty, wound-care burden, language-access needs, and task-level workflow surfaces. The failed pilots show that we were testing the wrong geometry too often: suggested restraint, loud chart facts, or genres where the model naturally verifies.

The correct response is not to edit the world. The world is frozen, and that rule stands. The correct response is to rebuild the remaining tasks as task-layer artifact problems with forced slots, realistic noise, and one material hidden signal.

## Corrected principle

The old shorthand was incomplete: "cold beats warm." The fuller rule is:

1. The signal must not be loudly solved by one or many obvious chart files.
2. The task must force a signable move, table row, disposition, or determination.
3. The wrong move must sit in a realistic task-layer artifact, not only in the prompt.
4. The prompt should stay short and clinical; the structure should do the forcing.
5. The grader must treat the central signability or safety miss as a hard failure.

Frozen world files only remove one lever. They do not remove task files, forms, worksheets, denial drafts, intake summaries, scanned artifacts, required tables, or binary determinations.

## Resource-file reset

The Raising Task Difficulty worked example did not win by adding more explanation. It won by changing information geometry:

- remove answer-key synthesis where possible
- force cross-document reconciliation
- add realistic task-level noise and required format
- bury a critical finding off the main prose
- align the grader with clinical stakes

Ondina cannot remove finalized world files, but it can still use the other four moves at the task layer.

The Quill exemplar also confirms the prompt style: one natural in-role ask. The complexity lives in the source packet and the grading target, not in a long prompt.

## Rescue slate

### 1. OV06 v2, first rebuild

Build a physician-advisor determination packet, not a free-text chart review.

Task file: a concurrent-review or physician-advisor worksheet with a prefilled conclusion that says the patient does not meet continued-stay or skilled-level criteria because fever, white count, renal function, and oral intake improved.

Prompt: short physician voice. Ask to review the packet against the chart, correct unsupported content, and produce the final determination in a document for signature.

Forced slot: final determination, approve continued stay or deny continued stay.

Floor: leaves the discharge-ready determination in place, or hedges without a binding call.

Catcher: acknowledges improvement but signs continued skilled-level need based on unresolved perfusion, wound-care frequency, offloading failure, stairs, and caregiver gap.

Why this can still work: the trap is not "find unresolved items." The model can do that. The trap is whether it will reverse a formal prefilled determination and commit to a binding decision.

### 2. OV08 v2, second rebuild

Build the missing task file. This is not optional.

Task file: a started vascular referral or triage intake draft that over-smooths perfusion as adequate or no urgent vascular issue.

Required output: referral letter plus disposition table for source control, perfusion, antibiotics, offloading, and follow-up.

Floor: perfusion adequacy or other open status survives in the final table or narrative.

Catcher: table keeps perfusion open using the raw ABI/TBI findings and formal vascular uncertainty.

Why this can still work: the current repo has not tested this mechanism. A chart-only referral prompt is not the same task.

### 3. OV04 v2, third rebuild

Build a started appeal draft with one self-defeating concession, not a plain denial rebuttal.

Floor: leaves a line saying home with routine follow-up is appropriate, or concedes medical stability as disposition readiness.

Catcher: strikes the concession and makes the appeal stand on the multi-domain unsafety picture.

### 4. OV09 v2, fourth rebuild

Do not bank on patient blame. The model avoids that by default.

Build a forced RCA form with required contributor categories. The scoreable miss is omission under load: language-access teach-back, device availability, order timing, home layout, and handoff clarity each need a mapped prevention step.

Floor: omits a required contributor or leaves prevention generic.

Catcher: complete contributor-to-prevention map.

### 5. OV03 only if rebuilt

The current CDI surface is suggested restraint and likely model-strong. Rebuild only if the task file embeds an over-affirmed physician/CDI response that must be reversed on clinical grounds. Otherwise retire.

## Operating decision

Stop spending pilots on old surfaces. Do not declare the world dead. Do not request a world-freeze exception yet. Rebuild one task at a time, starting with OV06 v2, and run the mount-tree gate before reading any score.

The next bankable task will come from structure, not volume. The world is frozen, but the task layer is still alive.
