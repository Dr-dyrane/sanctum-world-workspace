# OV05 v1 pilot result (off-text med-rec finding via med-bottle photo) - job eb1665ba - 2026-06-15

VERDICT: CEILING. No floor, 10/10 caught the ibuprofen. Lever NO-GO; retire.

Scores: 0.88 / 0.95 / 0.88 / 0.88 / 0.90 / 0.92 / 0.95 / 0.92 / 0.95 / 0.95. Range 0.88-0.95, mean ~0.92.

## Cause
The MEDICATION-RECONCILIATION genre PRIMES the model to examine every medication source, so the bottle photo was NOT off-text in this context - checking the bottles IS the task. Attempt 1 (representative of all): raw OCR returned nothing, so the model PROACTIVELY upscaled, grayscaled, thresholded, and OCR'd tile-by-tile across multiple PSM modes until it robustly resolved "IBUPROFEN 200 mg," then flagged and stopped it. The model worked HARD to read the image because a reconciliation demands it. Contrast OV04: the CPAP report is peripheral to a transition NOTE, so ~40% of runs never opened it and floored.

## Refined rule (update to the off-text-image engine)
The off-text-IMAGE lever floors only when the TASK does not prime examining that image AND the finding sits on an un-primed axis. A med-rec primes med-bottle examination, so a med-bottle-photo finding ceilings. More broadly: MED findings floor via COLD KNOWLEDGE the model lacks (OV01 enoxaparin stop-rule, BANKED), NOT via DETECTION (the model reliably detects meds in a med task; KM05 held-med restart also ceilinged). Detection of a med in a med task = primed.

## Disposition
Retire the OV05 med-rec-photo lever. The ibuprofen finding is detection-based and meds are a primed axis, so it is not floorable in a med task; re-pairing it with a non-med deliverable still primes meds and risks OV04 overlap. The build files (started med-rec, nursing note, image, golden, grader) are retained in platform/task5 for history; the slot reopens. Pivot to the distinct-structure, NON-detection levers in the path-to-8: #5 offloading-against-the-grain (floors via the eager "encourage mobility" move being wrong, not via detection) is the strongest next; #6 interpreter/consent omission next. Bench cold first.

## Note on the method
The off-text engine is sound (OV04 banked on it). OV05 misapplied it: it paired the image with a task that primes the image. The master principle holds - put the finding on an axis the TASK does not prime - and a med-rec primes meds. That is the design error, caught now at the pilot rather than at the bench (a priming risk was flagged in the OV05 Abi-mode review but under-weighted).
