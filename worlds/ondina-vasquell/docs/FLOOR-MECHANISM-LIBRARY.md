## 1. THE MASTER PRINCIPLE (the one thing) - PRIMED vs UN-PRIMED axis
================================================================
This model reads a clean chart EXTREMELY well and reflexively polices the things clinicians police. It therefore CEILINGS whenever the catch sits on a PRIMED/LOUD axis - one the model is already scrutinizing - and FLOORS only when the catch sits on an UN-PRIMED axis where the model has no reflex pulling it there.

- PRIMED / LOUD axes (model scrutinizes -> catches -> CEILING): vitals (it always re-reads a number against the trend), the deliverable's headline problem, any item the chart explicitly flags open/unresolved, patient identity (it guards against mix-ups), "don't restart meds without labs," "don't fabricate," "don't over-treat."
- UN-PRIMED axes (model has no reflex -> trusts or skips -> FLOOR): cold outside-knowledge it lacks; a quiet axis the chart is SILENT on the status of; a finding that requires proactive synthesis the completion frame suppresses.

Every OV result below is explained by this one axis. Design rule: put the catch on an UN-PRIMED axis, and never telegraph it.

The worked-example recipe is the operational form of this: (1) PULL THE ANSWER KEY (no file states the conclusion); (2) FORCE RECONCILIATION (no single file complete); (3) DON'T SPELL OUT THE TRAP (off-text / un-primed); (4) MATCH THE GRADER TO THE STAKES (hard cap); (5) KEEP IT TRUE TO PRACTICE.

KEY READS: over-closure FLOORS on an un-primed axis (CPAP) and CEILINGS on a primed one (anemia). Vitals, identity, restart-without-labs, over-treatment, fabrication are all primed -> those levers ceiling. IMAGES are NOT dead (OV04 banked on one), but an off-text image FLOORS only when the TASK does not prime examining it: OV04's CPAP report is PERIPHERAL to a transition note (the model can finish without it -> ~40% skip -> floor); OV05's bottle photo is CENTRAL to a med-rec (the model must read every med source -> 10/10 caught -> ceiling). Same lever, opposite result, decided by whether the genre FORCES the read. Corollary: MED findings floor via COLD KNOWLEDGE the model lacks (OV01), not via DETECTION (the model reliably detects meds in a med task). AGAINST-THE-GRAIN (the eager default is wrong) also CEILINGS when the correct restriction is loud in the chart (offloading: cold bench 3/3 caught + flagged); it floors only on a QUIET axis the chart does not already state, which this thorough chart rarely offers. REFINEMENT (2026-06-16 prelim-imaging bench, 3/3 ceiling both telegraphed and subtle): a finding buried in TEXT (a long report or note, even omitted from the impression) is READ and recognized at/above physician level -> ceiling. The OV04 image floor works because the model sometimes never OPENS the image file (~40% did not), NOT because the finding is buried. So "off-text" means an IMAGE the model may not open in a deliverable that does not force it - NOT "a buried line in text." The worked-example "buried line / prelim-imaging" tip does not hold for this model.

OFF-TEXT IMAGE RENDER METHOD + FAIRNESS (added 2026-06-17, OV09): the image IS the floor (the model may not open it), so the finding must live in a real IMAGE file, never a docx (text is always read -> ceiling). Two kinds of image. (a) Report / printout / scanned-study image: AUTHOR it through build_one and RENDER to image with LibreOffice (soffice convert-to pdf -> pdftoppm -> crop -> jpg; reference build/render_ov09_image.py), IN-REPO, no Codex, soffice runs in the build sandbox. (b) Genuine photograph or true film (wound photo, pill bottle, raw X-ray): needs a generative render (Codex / Nanobanana from an image spec); PIL and epic cannot produce photographs. FAIRNESS - the "why is this report an image" test: a report-as-image is only realistic when the genre is naturally an image (a device printout like OV04's CPAP report, or a SCANNED OUTSIDE study). An INTERNAL dictated report (radiology, labs) is normally text in the EHR, so imaging it is borderline and a reviewer can flag it; frame it as a scanned outside study or use the actual film. Matching the internal house style exactly makes the "why an image" question sharper, not softer. Full method: docs/docx-generation-method.md section 5.

HEADLINE-AXIS REFINEMENT (2026-06-17, OV09 v3 ceiling, job e9c38261): the embedded-wrong family floors only when the wrong element sits on a BACKGROUND axis the deliverable does not force the model to scrutinize, and CEILINGS when it sits on the deliverable's HEADLINE. OV08 floored because the antibiotic route was a background line in a UR worksheet whose headline was the continued-stay determination. OV09 v3 ceilinged 0.84 (range 0.72-0.92, no floor) because the embedded-wrong was the DISPOSITION in a post-acute coordination handoff, whose headline IS the disposition, so the model scrutinized and corrected it in all ten runs. This sharpens "primed": primed is not only the master-list axes (vitals, identity, restart-without-labs), it is whatever the specific deliverable makes its subject. Design rule: place the embedded-wrong on a routine background line, never on the deliverable's own headline. OV09 v4 re-cut the trap to a held-med resume on a routine discharge-medication line (background), disposition left correct. CONFIRMED 2026-06-18 (job cc337773): v4 floored bimodal, mean ~0.62 (four floors 0.25-0.35, five catchers 0.78-0.92), on the same chart, lane, and plain prompt as the v3 ceiling. Only the trap's location moved. The held-med resume is the OV03/OV06/OV08 satisfice family placed on a background line, and it is the eighth banked floor.

UNIFIED ENGINE (2026-06-16): the three banked floors (OV01/02/04) are ONE mechanism, not three. Under a "finish this" COMPLETION frame the model does the face-value completion and SKIPS a high-stakes step the deliverable does NOT force: OV01 copies an inherited inpatient med forward without re-evaluating discharge-appropriateness; OV02 fills the sections without assembling a prose-silent problem; OV04 writes the note without opening a peripheral image. Ceilings are the mirror - the deliverable FORCES the step (OV05 med-rec forces the bottles; AKI-RCA forces the nephrotoxin hunt; offloading is loud; text is always read; recency re-checked on loud axes). Cold-knowledge is NOT a separate engine: a 6/6 probe of OV-relevant facts (incl. enoxaparin) came back with no gap, so OV01 is application-under-completion, not ignorance. FLOOR #5+ = a NEW PAIR (a completion deliverable x a high-stakes step it does NOT force), not a new fact or mechanism. The bottle image has NO floorable home (any deliverable that makes the unlisted nephrotoxin relevant forces the med review - AKI-RCA bench 3/3 made it the central source).

## CEILING-ERROR LEDGER (2026-06-16) - we keep calling ceilings wrong, and it keeps costing OV tasks
================================================================
Standing warning: a COLD-BENCH CEILING IS NOT A VERDICT. Every time we have checked a cold-bench "ceiling" against the real agentic harness, the harness was harder on the model than the bench predicted. Cold benches use unhurried, careful reviewers. The harness runs a harried completion prompt over 35 files with tool-use, where the model SATISFICES. The bench measures the wrong agent.

Confirmed bench-vs-harness contradictions:
1. OV02 (off-text synthesis). Bench mixed and leaning ceiling. Harness FLOORED 10/10. First proof the bench overestimates catching.
2. OV03 hypoglycemia / discharge insulin. Cold bench 3/3 CEILINGED, and this file recorded that ceiling at the Hypoglycemia row. The harness FLOORED it 0.10-0.15 (job cb628a70). A written ceiling verdict, directly contradicted.
Add the early OV05 "image-blind" misread (we nearly excluded all image tasks; OV04 then banked on an image), and a whole cold-bench attrition round (offloading, prelim-imaging x2, recency, data-hierarchy, bottle-RCA, UR decisiveness, over-coding) that was DROPPED on bench alone and is now SUSPECT, because the one member we actually piloted (hypoglycemia) floored.

THEORY CORRECTION (satisfice): the PRIMED-vs-UN-PRIMED master principle is too strong as written. It assumed a "primed" axis is one the model always scrutinizes. The harness shows a primed axis still FLOORS when the completion frame suppresses the scrutiny. The model does not behave like the careful bench reviewer. It does the face-value completion and skips the step the deliverable does not force, even on an axis it "knows" to police. PRIMED predicts a ceiling only in an unhurried setting. Under the real completion frame, priming is weaker than the satisfice pull.

DISCIPLINE (binding): do NOT retire a candidate on a cold-bench ceiling. Bench to SCREEN and to catch telegraph errors, then BUILD and PILOT. Re-pilot the dropped attrition list (heel and C.diff first) rather than trusting their bench ceilings. A retired-but-never-piloted floor is an under-count, and we have under-counted at least twice.

## 4. REFINED BUILD + FAIRNESS RULES
================================================================
- Bench-first, ALWAYS, before any pilot. Cold reviewer, harness-matched, no golden/grader.
- Bench rule (text levers): reviewer-CATCH = ceiling signal -> rework/drop; reviewer-MISS/PROPAGATE = floor candidate -> pilot. (For the dead image lever this inverted, but images are out.)
- Do NOT telegraph in the bench: present the chart as the harness sees it; never pre-digest the contradiction or name the absence (the anemia-bench error).
- Fairness: the floor must be both INDEFENSIBLE-to-miss (real harm) AND FEASIBLE-to-miss (data as it really arrives). Easy+indefensible = ceiling; hard+defensible = no stakes.
- Frozen-world: task-layer artifacts only (started draft / mounted instrument / clinic note); reuse frozen files as backdrop; never edit world files (DO-NOT-REPEAT #21).
- Harness: image-blind (agent = bash, text only). No image levers. Mount only text the agent can read.
- Grader: five-block KM style, chart-aware, CAP the central failure (don't piecemeal-deduct), anti-paralysis floor (refusing to finalize is not free credit), credit correct restraint, verification-to-grader (treat output as untrusted, do not credit fabricated citations).
- FA/GA from the 2nd-LOWEST percent score (#20). One embedded re-roll then retire (#19).

## KM TRAP-PLACEMENT DISCRIMINATOR (from KM01 via the KM runbook, 2026-06-16) - why OV05 ceilinged 3x and RETIRED
================================================================
CORRECTION (2026-06-16, KM PERFORMANCE REPORT): the KM runbook INTENDED the salt substitute as KM01's central trap, but the KM01 PILOT shows the model DECLINED it. KM01 is the SOFTEST KM task (mean 0.89; FA subject = a prednisone-5mg-from-fill inference, not the salt substitute). So the salt substitute is a SOFT, reliably-declined trap in KM too, which independently validates retiring OV05. Do NOT cite KM01 as a salt-substitute FLOOR. The placement discriminator below still holds as KM design DOCTRINE; it just was not sufficient to floor KM01. The KM runbook discriminator:

A medication-safety or reconciliation deliverable PRIMES the model into maximal find-the-error mode, so anything that pattern-matches as an error gets caught. THE TRAP MUST NOT LOOK LIKE AN ERROR. KM made it work by (a) disguising the salt substitute as routine low-sodium-diet COUNSELING (not a flagged med decision), (b) burying it in the SAFE-items cluster, away from the obvious errors, (c) requiring INTEGRATION to reject (salt substitute -> potassium load -> hyperkalemia with the held ACE inhibitor), not recall, and (d) carrying it on an EXTERNAL pharmacy handoff so declining it is fair.

OV05 v3 did the opposite: listed the salt substitute as a DECISION beside the loud ibuprofen and lisinopril errors. That primed error-hunting and swept it up. 3rd OV05 ceiling (ibuprofen x2, salt substitute x1). OV05 RETIRED 2026-06-16 (Dyrane: trajectory keeps failing).

WHAT DOES NOT FLOOR (KM runbook, two red-teams): a buried fact alone (a strong model finds it); a chart-COACHED wrong rec (the model sides with the chart); a famous-fact error in a safety task (error-hunting sweeps it). FAIRNESS (KM A0.6): finishing a SAME-AUTHOR draft with a planted false line is UNFAIR (needs placeholder or correct-errors framing); responding to an EXTERNAL query/handoff with an unsupported option is FAIR to decline - the genre carries the fairness. OV06 (external vascular addendum) is on the fair side; OV05 v3's same-author resident draft was borderline.

RULE for OV07+: in any error-hunting genre, the discriminator must NOT look like an error, must require integration to reject, and must sit in the safe/routine cluster AWAY from obvious errors; prefer an external adversarial authority for fairness. The KM difficulty gate is mean at or below ~70 with several sub-70 runs and a low tail (~0.15-0.30) plus at least one trajectory with a real FA-able failure; "a score below 70 is useful evidence but not required." ## 8. PRODUCT READINESS LESSON FROM KM AND OV06 V2 (2026-06-17)
================================================================
OV06 v2 answers the mood question. The task did not fail because the world was weak. It floored once the prompt stopped telling the model where to look. Same chart. Same golden. Same grader. Only the telegraph was removed.

A perfect score is a failed difficulty task. KM was never supposed to produce perfect notes. KM proved the product by making a strong model fail on real physician judgment. Every clean task that merely asked the model to write the note correctly ceilinged. The score dropped only when the task forced one wrong move on an axis the model had no reflex to police.

Read every 0.90 OV pilot the same way. The model passed a test that was too easy. The world did not fail. OV05 and OV06 v1 were both evidence of this, and OV06 v2 is the correction.

The model's strengths are now mapped. It reads the chart, builds a source-traceable fact base, polices provenance, source hierarchy, held medications, and fabrication, declines a wrong external premise when asked to review it, runs rule-governed analysis cleanly, and finds buried text. Those strengths ceiling tasks.

The exploitable weakness is narrower. It does not reliably re-verify content it inherited under a completion frame. It treats a pre-filled claim as vetted. It has authority bias toward structured documents. It can treat unverified data as objective. It misses off-text or image findings when the workflow does not force opening them. It rubber-stamps an embedded wrong element when the prompt asks it to finish, not audit.

Fair hard tests use six rules:
1. Put the catch on a cold axis the model is not already hunting.
2. Force one wrong move so caution is not free.
3. Make the chart contradict the wrong move when inspected. Do not rely on chart silence alone.
4. Put the wrong move in a draft the model finalizes, or in an external document that is wrong by genre.
5. Do not telegraph. Do not add a reconcile clause.
6. Prove fairness with a catcher or a clean bimodal split.

OV06 paid for the telegraph lesson twice. v1 told the model to reconcile, and ceilinged. v2 let the wrong closure sit as routine started content, and floored. Keep that rule close.
