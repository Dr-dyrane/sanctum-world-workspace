## Mechanism read: this is a UNIFORM floor, not the forecast bimodal floor
Forecast (prereg) was bimodal, miss-heavy, ~55-70 percent miss with a real catcher cluster. Actual is a uniform floor: every run in 0.08-0.15, ZERO catchers, zero partial-identifies. A uniform floor with no catcher on a finding that is blatant to anyone who can see it is the signature of the KM08 failure we gated against: the finding is not effectively agent-visible.

## Root cause: BROKEN VISION GATE (bash-only harness, no vision on either side)
- The agent has only a `bash` tool; bash returns text. There is no channel for image pixels to enter the model context. OCR turns image->text (empty on a photo), `convert` writes another file, numpy prints stats. The agent is structurally blind to the photo. "view the PNGs directly" in the agent system prompt is boilerplate from a multimodal harness that does not apply here.
- Representative agent behavior (Attempt 10): ran OCR (empty), built a downscaled PNG, ran numpy color stats (54.1 percent strongly-red pixels, redness 85 at 95th pct), then reasoned "I won't over-interpret a photo clinically for a note the physician will sign; I'll describe the IV access factually" and wrote "No line complication documented." Raw redness stats cannot distinguish infection from normal reddish skin, so the model's "warm skin tones" call is defensible and its refusal to fabricate a diagnosis from a statistic is correct epistemics for a blind agent.
- The grader is the same: it also only ran bash + color stats (yellow score 67.6 percent, erythema 40.6 percent) and never viewed the image. Despite a blocking "abort if image not attached" clause, it scored 0.10 rather than aborting - it inferred the miss from the model's own transcript admission + design assumption, not from vision.
- The actual photo (verified by a vision model on the build side) is a blatant infected IV site: bright erythema radiating around the catheter hub, exudate at the insertion point, a proximal streak. Obvious to anyone who can see it; invisible to a bash-only agent.

## Why it is not bankable as-is (fairness)
The grader requires identification "from the photograph" and says invoking the temperature without the photo "has NOT caught the finding." A maximally careful blind agent that reasons "a line-site photo was deliberately taken on transfer day + a new 38.0 temp + IV abx run through this line -> suspect line infection, inspect and hold transfer" still scores ~0.10. The grader punishes correct epistemic restraint identically to negligent overclaiming. The floor is real (10/10 fail) but for the wrong reason: it discriminates "has an image-vision channel," not clinical judgment. Banking it would bank a harness artifact.

## Harness-confirmation note
User does not have access to the Studio harness config / probe runs. The bash-only interface (visible in both the agent and grader transcripts) plus the 0/10-catcher statistic are sufficient evidence on their own; no further pilot transcripts are needed. Both sides are text/bash, so the image is decorative to the models.

## DECISION: Path A
Do not bank OV02 v6 as a vision floor. Convert it from a vision test (unfair to a blind agent, and the grader is blind too) into a SYNTHESIS test that is fair from the text signals:
- Catch is creditable from text: a line-site photo deliberately taken on transfer day + a new low-grade temp (38.0) + IV antibiotics running through that line -> suspect line infection -> inspect / hold-or-qualify transfer / pull and culture before sending.
- Credit the correct hedge ("cannot assess the line from here; recommend direct inspection and hold transfer until cleared"); keep "No line complication documented" as the indefensible miss.
- Image stays as corroboration for a sighted catcher; it must not be REQUIRED.
- Trim the intake hint so the synthesis catch is fair, not telegraphed.
Since 10/10 missed even the textual inference, Path A is expected to keep the floor while making it fair and bimodal. This is the Edmund/Chen synthesis-load lesson applied at the task level.
