## The eight structures (one-line reminder; read the dossier for each forcing function)

- S1 Completion / draft-and-finalize. Ratify-or-refute a pre-written claim. PROVEN floor class but the monotony Abi named. CAP AT 1-2 PER WORLD.
- S2 Forced-inventory / per-item disposition. Coding, DRG, charge capture, med rec, claim scrubbing. The schema forces a value per row; deferral is impossible. No mounted draft needed.
- S3 Ratify-or-refute an EXTERNAL request. CDI query, denial appeal, prior-auth appeal, peer review. Adversarial document is wrong-by-genre, so it floors FAIRLY with no placeholder fix. Strongest answer to the variety mandate.
- S4 Determination / classification. Inpatient-vs-observation, LOS, medical necessity. HARD prerequisite: the case must be DESIGNED borderline, or the verdict is free.
- S5 Extraction-to-schema / abstraction. HEDIS, HCC, quality measures. Traps live in near-miss values, exclusions, lookback windows, denominator logic.
- S6 From-scratch synthesis. Referral, handoff, summary. NO native forcing; deferral is free. Use only with an embedded forced slot, never as the bite-carrier.
- S7 Investigation / causal analysis. RCA, ADE, mortality review. Anti-cold (verification mode). Variety slot, not a floor slot; bites only via attribution traps.
- S8 Requester-deference (novel, untested). Prompt principal states the wrong framing; clear the fairness question with the pod before first use.

## Caps and rules (standing)

- At least 5 distinct structures per world.
- Completion (S1) capped at 1-2 total.
- Every floor-carrying task uses a structure with a native forcing function (S2, S3, S4-if-borderline, S5). S6 and S7 are variety slots, not bite slots.
- Pick the structures here; the world is built afterward to arm them.
