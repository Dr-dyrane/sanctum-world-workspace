# World 3 Image Sourcing Checklist (Marva Lydell)

Date 2026-06-18. Standing rule for any off-text image asset in World 3. Carries the OV and KM image lessons and the 06/18 Project Sanctum resource list (reference/source/task-selection-categories/Project_Sanctum_Resources_by_Category.docx). Planning guidance only; no world file, task artifact, prompt, grader, or image is authorized at the current Brainstorm checkpoint.

## Why this exists
The 06/12 worked example shows the off-text image is the single strongest difficulty lever: a critical finding visible only in an image plus one quiet vital did most of the work. That example used a Nanobanana (AI) render, and Larry's 06/18 rule bans AI-generated imaging. This is how World 3 keeps the lever without an AI render and without copyrighted images.

## Two hard constraints
- No AI-generated imaging (Larry, 06/18). A Claude-rendered text-to-image of a report or printout is allowed. A generated photo or film is not.
- No copyrighted images. Public domain or CC0 only. CC BY-SA is a fallback, used with attribution recorded and the license verified on the file page.

## Source order (use the first that fits)
1. In-repo render (DEFAULT). Author the artifact through build_one, then soffice to pdf, pdftoppm to png, crop. Use for every device printout and report: ambulatory or six-minute-walk oximetry, telemetry or AFib rhythm strip, home-scale or remote-monitoring printout, scanned vendor delivery-failure fax, lab or radiology report. No external asset, no license, no AI. This covers nearly all of World 3's planned off-text assets (Master Packet Part 5).
2. In-house Project Sanctum simulator. When a realistic device screen is wanted that the renderer cannot make: lab report (tab 1), radiology report (tab 2), live patient monitor (tab 3), EKG (tab 4), ventilator (tab 5) at med-data-nine.vercel.app, plus the EKG, EEG, and EFM sims on kingpascual1992-cmd.github.io. Screenshot the generated artifact. In-house, no external license, no AI.
3. Public-domain image. Only for a true photo or film the steps above cannot produce. Prefer US-government public domain (CDC PHIL, NIH). Wikimedia Commons is acceptable only for files tagged Public Domain or CC0, verified on the file page; never a Wikipedia non-free or fair-use image. NIH, CDC, WHO are true public domain; Radiopaedia and LITFL are CC BY-SA, so they are the attribution-required fallback.

## Per-asset gate (clear every line before the asset is mounted)
- Why-is-this-an-image test passes. It is a device printout, a scanned form, or a genuine film. Anything a chart would carry as prose stays prose. Forcing the read ceilings (the OV05 bottle-photo lesson).
- Not the scored trap by itself. The image is mounted agent-and-grader visible, and the finding is corroborated by one quiet line or vital, never the only evidence.
- Source path is 1, 2, or 3 above. No AI generation anywhere in the chain.
- If sourced (path 3): license is PD or CC0, or CC BY-SA with attribution recorded; metadata scrubbed; the clinical content matches the chart (right modality, right finding).
- Timelessness. World 3 snapshot is 07/10/2025, all dates on or before 07/31/2025. No visible later date, device format, or guideline version that postdates the world.
- Provenance recorded in the task design doc: source, license, scrub note, and the corroborating quiet line.

## World 3 note
Nearly every planned off-text asset is a device printout or report, so path 1 is the default and path 3 should be rare. Reserve sourced public-domain images for a genuine film or photograph a task specifically needs, and try the in-house simulator before reaching outside.
