## Method

The name needs to behave like Korvin Merrow and Ondina Vasquell: memorable, pronounceable, clinically neutral, and not close to any existing patient or clinician name in the repo.

Because the demographic direction is a Black older adult woman, the shortlist should fit that chart context without becoming a stereotype or a scoring cue.

Local collision scan was run against the repo for the shortlist names. No matches were found. Exact-name web checks were also run for the recommended group to avoid an obvious public-person match.

## Recommendation

Approved patient name: Marva Lydell.

Why this works:

- Distinct from Korvin Merrow and Ondina Vasquell.
- Easy to say and remember.
- Believable for a Black older adult internal medicine chart.
- Has a clear, dignified patient-world identity without reading like a public figure.
- Does not sound like a disease, drug, brand, or hospital system.
- Gives the world a clean repo slug: `marva-lydell`.
