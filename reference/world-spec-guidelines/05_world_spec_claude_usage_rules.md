# World Spec Claude Usage Rules

## Source-Of-Truth Rule

Claude is expected in the Sanctum workflow, but Alexander remains the clinical source of truth. Claude may organize, structure, and audit. Claude must not replace physician judgment.

The official World Spec prompt starter begins only after Brainstorm has been signed off by a Team Lead or assigned reviewer.

## When Claude Is Required Or Expected

Use Claude after Brainstorm GO to:

- Load the approved Brainstorm.
- Walk through every World Spec Template section.
- Present options and pros/cons where there are real design choices.
- Interview Alexander before drafting.
- Run systematic audit before drafting.
- Draft structure and consistency only after Alexander confirms readiness.

## What Claude Must Not Generate

- Final task prompts from scratch.
- Scenario concept.
- New traps.
- New task ideas.
- New clinical facts, labs, dates, medication doses, file names, or numerical anchors not provided by Alexander or source material.
- Golden responses.
- Grader guidelines.
- Failure analysis.

## Official Claude Interview Phases

1. Load the approved Brainstorm.
2. Clinical Scenario.
3. Task Specifications.
4. World File Plan.
5. World Summary.
6. Systematic audit before drafting.
7. Draft the World Spec only after confirmation.

## Required Claude Inputs Before Use

- Approved Brainstorm DOCX or pasted text.
- Official World Spec template.
- Approved task selection tracker.
- Alexander's physician-originated decisions for each interview section.

## Local Codex Role

- Prepare Claude-ready input.
- Tell Alexander exactly when Claude is required versus optional.
- Audit Claude output against physician intent, source guide, template, checklist, and realism standards.
- Reject unsupported additions.
- Preserve Claude output separately as review/drafting artifact if imported.
