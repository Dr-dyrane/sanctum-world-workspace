## Template Structure Observed Locally

The local DOCX contains:

- 85 paragraphs
- 20 tables
- Four main sections

## Section Map

### 1. Clinical Scenario

- 1.1 Big Picture Summary
- 1.2 Patient Profile (customize as needed)
- 1.3 Clinical History and Context
- 1.4 Key Milestones (Compressed Timeline)
- 1.5 Clinical Complexity Overview

### 2. Task Specifications

Template provides task blocks. Each task block includes:

- Task title
- Workflow
- Draft Prompt
- Expected Output
- Failure Design
- Task-level files

### 3. World File Plan

- 3.1 Essential Files (World-Level)
- 3.2 Essential Files (Task-Level)
- 3.3 Supplementary Files
- Total file count

### 4. World Summary

- 3-5 sentence summary of what the world tests, why the trap architecture works, and why the world is difficult.
