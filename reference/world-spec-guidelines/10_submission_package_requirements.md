# World Spec Submission Package Requirements

Source scope: `reference/source/New Writers Version - Instruction Guide (05_24).md`, local template/link indexes under `reference/templates/`, and existing source-derived World Spec guideline files.

This file records only source-of-truth evidence. Where the source does not state an answer, the finding is marked `Not found`.

## Core Findings

### 1. What files are uploaded during World Spec submission?

Evidence found:

- World Spec document:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:197` says to upload the World Spec to RL Studio, run AutoQC, address audit items, and re-upload as needed.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:850` says, under Stage 2 upload, "Upload your World Spec document."
  - `reference/world-spec-guidelines/08_autoqc_master_index.md:116` says the spec must be a single `.docx` file.

- Template/reference files:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:852` says to upload "any template/reference files needed for the spec" for the engineering team.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:1338` says the Reference Templates folder and world spec are uploaded together to RL Studio for engineering handoff.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2448` says to upload the World Spec plus world-level template selection plus custom-made world-level files.

- Custom-made world-level files:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2444` says to self-QC the finalized World Spec and curated world-level template selection plus custom-made world-level files before uploading.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2448` says custom-made world-level files are included in the RL Studio upload package.

- Writer-produced media/artifacts, if present:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:1338` says writer-produced media bypass the engineering pipeline and are uploaded directly.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:1887` says writer-produced media bypass engineering and are uploaded directly.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2424` says writer-produced files must be uploaded alongside templates as a complete package.

- Each file is separate:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2106` says each file is a separate upload and not to package into a zip.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2448` also says each file is a separate upload.

Important source conflict:

- `reference/source/New Writers Version - Instruction Guide (05_24).md:432` says that during onboarding, writers upload the spec only and veteran writers upload Reference Templates at Step 4.
- Later source sections say the updated May 20, 2026 workflow includes new writers curating Reference Templates alongside the world spec:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:1887`
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2399`
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2448`

Because the source contains both statements, the package should be treated as requiring confirmation in RL Studio or Slack before upload if the upload form asks for template/reference files during onboarding.

### 2. What are "template/reference files"?

Evidence found:

- `reference/source/New Writers Version - Instruction Guide (05_24).md:1338` defines the Reference Templates folder as holding the boilerplate template or reference file for each world-level file row in the file plan. Sources include internal DataBank templates, public domain forms, and custom-made outlines.
- `reference/source/New Writers Version - Instruction Guide (05_24).md:2424` defines document-based templates/reference files as progress notes, consult notes, discharge summaries, lab reports, imaging reports, forms, and similar text-based clinical documents curated from DataBank, public domain, or custom-made origins.
- `reference/source/New Writers Version - Instruction Guide (05_24).md:2470` says engineering relies on reference templates that match the format of the envisioned world files.

### 3. What are "custom files"?

Evidence found:

- Custom-made templates:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2374` defines a custom-made template as drafted by the writer, potentially with Claude's help, and still a template rather than a final file.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2393` lists custom-made templates as the writer's own outline for a specialty document.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2424` says Claude may draft custom-made templates as `.docx` files in collaboration with the writer.

- Writer-produced files:
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2376` defines writer-produced files as actual finalized files created by the writer using specialty tools; engineering does not convert them.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2396` lists examples: custom EKG, EEG, ventilation tracings, real-world photos, clinical imaging, audio files, lab reports, and recently published articles.
  - `reference/source/New Writers Version - Instruction Guide (05_24).md:2424` says non-pipeline media artifacts are produced by the writer via tools such as Nano Banana Pro, ElevenLabs, GarageBand, Photoshop, or similar external tools.

Required:

1. Single World Spec `.docx`.
   - Evidence: `reference/source/New Writers Version - Instruction Guide (05_24).md:850`; `reference/world-spec-guidelines/08_autoqc_master_index.md:116`.

2. World-level template/reference files needed for the spec.
   - Evidence: `reference/source/New Writers Version - Instruction Guide (05_24).md:852`, `:1338`, `:2448`.

3. Custom-made world-level templates.
   - Evidence: `reference/source/New Writers Version - Instruction Guide (05_24).md:2374`, `:2424`, `:2448`.

4. Writer-produced world-level files or media artifacts.
   - Evidence: `reference/source/New Writers Version - Instruction Guide (05_24).md:2376`, `:2396`, `:2424`.

Upload handling:

5. Upload each artifact individually; do not zip.
   - Evidence: `reference/source/New Writers Version - Instruction Guide (05_24).md:2106`, `:2448`.

- Claude transcript file or transcript format.
- Brainstorming transcript.
- Separate Brainstorm document upload during Stage 2 World Spec submission.
- Task prompts, golden responses, grader guidelines, or failure analysis during World Spec submission.
