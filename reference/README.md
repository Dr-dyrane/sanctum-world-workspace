# reference/ - official Sanctum source, templates, and derived guidance

Map of this tree. For the source-of-truth index, read `source/README.md`.

- `source/` - external/official Sanctum materials, organized by purpose (instruction doc, task categories, Phase 3 capture, AutoQC section guides, worked examples, media). Current versions sit in purpose folders; prior versions under `source/_superseded/`. Start at `source/README.md`.
- `templates/` - blank section templates (World Spec, AutoQC Sections 2-4, brainstorm) AND the Quill latest-guidance worked example. See `templates/README.md` for which is which.
- `world-spec-guidelines/` - numbered, distilled World Spec authoring guidance (01-13) plus standing policy and pod-announcement files.
- `checklists/` - preflight checklists: brainstorm, world-spec, spec-autoqc, reviewer-failure-patterns.
- `workflows/` - reusable planning canvases and the onboarding pipeline. Historical next-world (Ondina DFI) prep is grouped under `workflows/_history-ondina-dfi/`. See `workflows/README.md`.
- `world-spec-examples/` - full example worlds (Harold, Marcus, Opus, Quill, Chen) for reference; large, nested by world.
- `skills/` - local copies of skill references (FA/GA, preference labeling).

Rule: cite the current source via `source/README.md`; never cite a `_superseded/` or `_history-*` file as current.
