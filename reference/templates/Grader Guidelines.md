**Task 3 Grader: CDI Physician Query Set**

Deliverable: a CDI physician query set authored by Marsh of the CDI program, as a retrospective pre bill review of the index admission, built from the full chart and the wound consult. The output is a set of compliant queries with chart traceable indicators, an addressee, a query type, non leading language, balanced options, and a coding or quality impact. CDI templates and compliance phrasing are authentic voice. 

*Reference golden: Golden\_Task\_3\_CDI\_Query\_Review.docx*

This is one defensible query set, not the only one. 

Register note: a CDI query set is written in compliant, template driven program voice. Authentic CDI phrasing and structured query language should be read as register rather than penalized, and overly polished prose should not be rewarded over a sendable, compliant query.

**Non Negotiables**  
The output is a set of CDI queries, not a rewritten diagnosis list, a coding assignment, or a management plan. Every query is non leading: it pairs the chart indicators with a clarification ask, balanced options, and a clinically undetermined or insufficient documentation out.  
A sacral pressure injury query is required: it asks for stage and present on admission status from the wound documentation and the absence of admission documentation, without asserting a stage. A malnutrition and sarcopenia query is required: it uses the CF and pressure injury context, the low BMI and weight, the documented severe protein calorie malnutrition and sarcopenia, and the rehab and healing needs as indicators. A principal diagnosis and etiology query is required: it is framed open and non leading with balanced options and a multifactorial, other, or undetermined path that lets the provider supply the DIOS, TIPS, cirrhosis, or sarcopenia etiology rather than being handed a pre packaged causal answer, with ACLF, seizure, and sepsis left available. The set does not query unsupported ascites from diuretics, and it does not over query settled documentation when there is no coding, SOI, DRG, HCC, or quality gap.

**Scope and Legitimate Variation**  
There are typically three focused queries. Compliant anatomy is title, addressee, type, indicators, the question with options, coding relevance, and a response and signature line. Equivalent compliant layouts are fine, including separated queries, a cover summary with query text, or a table with full language, as long as the result is sendable to a provider. Type may vary, for example multiple choice for stage and present on admission and for malnutrition, and open with structured options for the principal diagnosis. The addressee is the attending of record or the provider responsible for the gap; the wound RN supplies indicators, but the query goes to a documenting provider. A deferred or not queried section is not required; a brief one explaining why ascites, seizure, or settled pneumonia are not queried is acceptable, but a sprawling low yield audit is scope drift. Use the golden as your calibration anchor for what the source files support. It is one valid completion among many, not the only correct answer, and it cannot encode every clinical fact in the world. Reasonable expert divergence from the golden is not fabrication when it is supported by the source files; Section B names the variations that are pre vetted as acceptable. Fabrication means clinical content that is not supported by the source files, whether or not it is defensibly argued. When the output diverges from the golden, ask whether the source files support it: if they do, do not penalize it as fabrication; if they do not, treat it as fabrication. Watch in particular for a stated wound stage, present on admission status, organism, sepsis status, exam finding, or dietitian quote presented as fact, and for unsupported coding targets such as ascites, a definitive stage, or primary seizure or sepsis named as the coded driver.  
Format is secondary.

**Common Failure Modes**  
These are patterns to reason about, not items to tick off.  
\-Writing a corrected diagnosis list instead of queries.  
\-Making the wound query leading by asking to confirm a specific stage, which is both a compliance failure and a fabricated stage.  
\-Underweighting sarcopenia as routine nutrition, which loses both SOI and the physiologic explanation.  
\-Anchoring the principal diagnosis on ACLF, sepsis, or seizure instead of a non leading clarification.  
\-Querying ascites off the diuretics, which manufactures a condition.  
\-Omitting the undetermined option, which makes the query noncompliant and leading.
