# Edmund/Chen example world - difficulty-engine distillation
Date: 2026-06-15. Author: Claude (cowork), from a full read of the six-task Edmund/Chen example package (prompts + goldens + graders for T1-T6). The raw example docx live at `reference/world-spec-examples/edmund-chen/` but that path is GITIGNORED (line 66), so this distillation is the committable record of what the examples teach. Purpose: correct and deepen the OV floor-engineering model with evidence from a built suite that floors on this model.

## The world in one line
62M, ESBL E. coli urosepsis, course complicated by AKI (Cr 1.2 baseline -> 3.6 peak), cefepime UNDER-dosed for renal function -> cefepime neurotoxicity (encephalopathy + myoclonus), missed by every consultant during the stay, then RE-DISPENSED at home by infusion pharmacy -> ED return. 80-file chart. Mandarin-speaking wife / HC-POA.

## The single most important finding (corrects a prior OV assumption)
Every one of the six tasks has the SAME clinical answer (cefepime neurotoxicity from renal under-dosing, re-dispensed at home). Difficulty does NOT come from an exotic answer or from a single embedded error. It comes from HOW HARD THE ANSWER IS TO ASSEMBLE against a deliberately hostile information field.

This reframes the OV "embedded-wrong vs suggested-wrong" model. The deeper axis is SYNTHESIS LOAD:
- OV01 banked because reconciling 16 meds across home-list/MAR/hold-orders is genuinely effortful; the embedded enoxaparin error sat INSIDE real synthesis work.
- OV02-OV10 ceilinged because each was ONE clean correction in a LOUD, INTERNALLY-CONSISTENT 34-file chart. Low synthesis load, single answer, no competing authorities, no decoys -> the model walks straight to it.
- Edmund floors because its 80-file chart has CONFLICT AND NOISE ENGINEERED IN: conflicting authoritative sources, decoy patients, corrected errors, copy-forwarded narrative. The answer is knowable but BURIED.

Root cause of OV's ceiling problem is therefore SUBSTRATE, not trap cleverness: DO-NOT-REPEAT #1 ("world built before traps") + a chart deliberately built internally consistent. Edmund was built WITH conflict as the substrate from day one.

## The four floor mechanisms the examples actually use (all robust, none "catch one wrong line")
1. CONFLICTING AUTHORITATIVE SOURCES (T1 progress note, T4 discharge summary). Three consultants each reached a DEFENSIBLE-but-wrong conclusion: neurology = metabolic encephalopathy (defensible - they did not review the MAR), cardiology = embolic infarcts (defensible - MRI is real), attending = copy-forwarded "improving on appropriate therapy" for 5 days while Cr rose. The model must REJECT all three authorities and reach the diagnosis NONE of them did. The failure mode is DEFERRING TO A WRONG AUTHORITY. This is the cleanest, most repeatable floor lever in the set. KEY FAIRNESS BAR: each wrong authority is wrong FOR AN UNDERSTANDABLE REASON. Neurology's call is defensible given what they saw. That is what separates this from OV06's failure (a worksheet that mischaracterizes findings it simultaneously quotes = self-incriminating, swatted away instantly).
2. ADVERSARIAL NOISE / CROSS-TALK CONTAMINATION (T6 ambient transcript). The transcript weaves in ~15 OTHER patients with deliberately overlapping features: Bed 9 near-identical (PICC, meropenem, E. coli, Cr 1.2->2.8), Bed 8 (confusion, warfarin, AFib, prior stroke, daughter voice overlapping the wife at 17:20), "cefepime" spoken about Bed 11 with NO connection to Chen. Plus CORRECTED ERRORS (age 64->62, PICC right->left, weight 80->70.2, baseline Cr 1.4->1.2) and a THIRD-PARTY MISINTERPRETATION the attending explicitly rejects ("she gave the wrong medicine"). The transcript NEVER names the diagnosis - the model must derive it from the chart while NOT contaminating the note with any decoy. Any other-patient data in the Chen note = patient-safety failure.
3. ANALYTICAL RIGOR UNDER STRUCTURE (T3 RCA). The diagnosis is easy; the floor is STRUCTURE. Section B (methodology) is weighted EQUAL to Section A (root cause). Must separate proximate vs root vs contributing cause, cite four policies by number (ASP/IT/PHARM/MED-2025), group contributing factors, produce owned+timed corrective actions. Education-only fixes are capped. A model that nails the diagnosis but blurs causal levels scores 0.5-0.7, not 0.9.
4. COMMISSION / DECISIVENESS UNDER PRESSURE (T5 ED return, T2/T4 meds). T5: causative agent must be STOPPED in the ED, not "consider discontinuing" - equivocal language is explicitly penalized. T2/T4: the auto-generated list carries cefepime as ACTIVE (the embedded re-exposure error) plus an 11-disposition reconciliation (continue/stop/hold/new) where conflating HOLD with STOP is a central safety failure.

## Cross-cutting craft patterns worth copying
- VERIFICATION INSTRUCTIONS TO THE GRADER: every grader says "treat the model's output as untrusted claims to be verified" and "spot-check policy numbers / Att-file citations against source; do not award credit for citations that do not exist." Anti-hallucination baked into grading.
- PLANTED-CITATION TRAP: the chart has real Att-file numbers (Att-56 ID note, Att-73 home-infusion record, Att-01 baseline Cr); a model that fabricates a citation gets caught.
- THE "BASELINE Cr 1.2 not 1.4" TRAP recurs in EVERY grader's known-errors: using admission Cr (1.4) or discharge Cr (2.4) as baseline instead of documented pre-illness 1.2 (Att-01) understates AKI severity. A single quiet number planted across the chart that the model must get right.
- SUPERSEDED-RECOMMENDATION TRAP: ID's HD3 "continue cefepime" was SUPERSEDED by ID's HD10 reassessment (same service, different data). A model that treats the earlier recommendation as operative fails. (This is exactly the OV "which note wins" axis, done with same-author supersession.)
- PROMPT REALISM / TIME PRESSURE: every prompt is a harried clinician voice ("It's 3 PM, sign-out is at 4, I've never seen these patients"). The pressure frame discourages exhaustive chart review - the model that rushes misses the buried answer. This is a difficulty lever in the PROMPT, not just the chart.
- PHYSICIAN-PRODUCED + FACINGNESS: T2 list is patient-facing ("By mouth", plain language); T4 summary is physician-facing (clinical shorthand). Same content, register graded. Mismatched register is penalized.

## Direct implications for OV (carried into scrutiny + next-world canvas)
1. OV's "1-2 floor world" outcome is a SUBSTRATE limit, not a trap-design failure. The chart is too small (34 files) and too internally consistent to bury an answer Edmund-style.
2. The highest-yield single change available to OV (IF a one-note freeze exception is granted) is to introduce ONE CONFLICTING AUTHORITY (T1 pattern) - e.g., make the existing vascular note conclude "perfusion adequate, no further workup," contradicted by its own toe-pressure data, so the task becomes which-authority-do-you-trust instead of catch-the-embedded-error. One conflicting authority outfloors five clever embeds.
   - FAIRNESS GATE on that move: the wrong authority must be wrong for an understandable reason (defensible on partial data), NOT a self-incriminating mischaracterization (the OV06 trap).
3. The NEXT world must be built with conflict/noise/decoys/competing-authorities AS THE SUBSTRATE from day one. "Traps before files" really means "CONFLICT before files." This is the canvas-level lesson.
4. Prompt-level difficulty (time pressure, harried voice, "I haven't read the chart") is a free, world-frozen-safe lever OV under-uses.
