# docs/ - lessons, playbooks, and operating doctrine

Durable knowledge for building Sanctum worlds, grouped by purpose. Live project STATE is not here; it lives in root `WORKSPACE_FILE_MAP.md`, each world's cockpit (`worlds/<world>/00-START-HERE.md`), and the dashboard.

## Read first (doctrine)
- `anti-hallucination.md` - the one rule: read the latest primary artifact, never a stale summary. Seven levers.
- `reasoning-discipline.md` - verify ground truth at one-way doors and before platform-causality claims.
- `workspace-guardrails-lessons.md` - the operational guardrails ledger.

## World building (brainstorm to spec)
- `world-factory-playbook.md` - the repeatable brainstorm to spec to reference-files pipeline. READ FIRST for a new world.
- `world-pipeline-playbook.md` - the KM forward pipeline and longer-form method notes.
- `task-structure-dossier.md` - the eight task structures; pick 5+ before designing the patient.
- `task-difficulty-lessons.md` - why a task is hard and fair; the fairness doctrine.
- `edmund-chen-difficulty-engine-distillation.md` - difficulty-engine distillation.

- `docx-generation-method.md` - the deterministic DOCX build and QC method.
